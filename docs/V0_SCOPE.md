# DAN V0 scope (실사용 직전)

BUY/SERVICE 입력 + 현재 위치 + 만료/상태 + 상세 CTA까지가 **V0 끝**.
여기 이후는 **더 붙이지 말고 실제 사용자에게 써보게** 한다.

## 상태 흐름 (SERVICE 등)

```text
ACTIVE (모집 중)
  → MATCHED / CONNECTED   응답 수락·연결
  → CLOSED                작성자 마감
  → EXPIRED               희망 시간/만료 시각 경과 (자동)
```

결제·별점·분쟁은 만들지 않는다.

## CTA

| 상황 | CTA |
| --- | --- |
| 작성자 + ACTIVE | 수정 / 요청 마감 |
| 다른 사람 + ACTIVE | 제가 할게요 (BUY는 가지고 있어요) |
| MATCHED/CLOSED/EXPIRED (비연결) | 마감된 요청 |
| 내가 연결된 쪽 | 대화하기 |

## 위치

- 현재 위치 사용 시: 카드에 `약 800m` / `약 2.3km` (뷰어 좌표가 있을 때)
- 연결 전: 상세 장소 설명·좌표 숨김 (지역명 또는 거리만)
- 직접 입력: `평택역 근처` 그대로

## 만료

- SERVICE/TASK/BORROW: `expires_at` = 희망/마감 시각
- BUY: 기본 30일
- 피드·응답은 지난 요청을 열지 않음

## V0에서 안 만들 것

- AI 문장 교정
- 리뷰 / 별점
- DAN 자체 결제
- 복잡한 지도 UI
- 실시간 위치 추적
- 채팅 안 가격 협상 기능
- 카테고리 수십 개
- 대화형 요청 위저드

막히는 지점을 실사용에서 보고 다음 기능을 정한다.
