# DAN V0 scope (실사용 직전)

BUY/SERVICE 입력 + 현재 위치 + 만료/상태 + 상세 CTA까지가 **V0 끝**.
여기 이후는 **더 붙이지 말고 실제 사용자에게 써보게** 한다.

## 상태 흐름 (SERVICE 등)

```text
ACTIVE (모집 중)
  → MATCHED / CONNECTED   응답 수락·연결
  → CLOSED                작성자 마감
  → EXPIRED               희망 시간/만료 시각 경과 (자동)
```

결제·별점·분쟁은 만들지 않는다.

## CTA

| 상황 | CTA |
| --- | --- |
| 작성자 + ACTIVE | 수정 / 요청 마감 |
| 다른 사람 + ACTIVE | 제가 할게요 (BUY는 가지고 있어요) |
| MATCHED/CLOSED/EXPIRED (비연결) | 마감된 요청 |
| 내가 연결된 쪽 | 대화하기 |

## 위치

- 현재 위치 사용 시: 카드에 `약 800m` / `약 2.3km` (뷰어 좌표가 있을 때)
- 연결 전: 상세 장소 설명·좌표 숨김 (지역명 또는 거리만)
- 직접 입력: `평택역 근처` 그대로

## 만료 (V0 고정)

> **시간성 요청은 약속 시간에 만료 / 지속성 구매 요청은 30일 / 만료 후 사용자가 직접 연장**
> 자동 재게시는 하지 않는다.

| 유형 | 만료 |
| --- | --- |
| SERVICE / TASK / BORROW | 희망·마감 시각. 날짜만(로컬 00:00)이면 **그날 끝**에 만료 |
| BUY | 생성 시 +30일. 만료 후 `아직 찾고 있나요?` → **30일 연장** (자동 연장 없음) |
| MATCHED | 만료하지 않음. `MATCHED → CLOSED`로만 정리 |

- EXPIRED: 피드·공개 응답에서 즉시 숨김, **My DAN에 기록 유지**
- BUY 만료 CTA: `30일 연장`
- 시간성 만료 CTA: `비슷한 요청 다시 만들기` (새 요청 작성, 자동 복제 없음)

## V0에서 안 만들 것

- AI 문장 교정
- 리뷰 / 별점
- DAN 자체 결제
- 복잡한 지도 UI
- 실시간 위치 추적
- 채팅 안 가격 협상 기능
- 카테고리 수십 개
- 대화형 요청 위저드

막히는 지점을 실사용에서 보고 다음 기능을 정한다.
